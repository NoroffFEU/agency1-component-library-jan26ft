# Profile Card (composite)

Et profilkort satt sammen av flere mindre komponenter: avatar, navn/tittel, tre ikon-lenker (GitHub, e-post, LinkedIn) og en kontaktknapp.

## Funksjonalitet

Ved klikk på «Contact me»-knappen kopieres e-postadressen til utklippstavlen, og knappeteksten endres midlertidig til en bekreftelse før den bytter tilbake.

## Struktur

- `index.html` – markup for kortet
- `style.css` – all styling, inkludert fargevariabler i `:root`
- `script.js` – klikk-håndtering og kopiering til utklippstavle

## Ikoner

Ikonene er hentet fra [Font Awesome](https://fontawesome.com) via CDN.
