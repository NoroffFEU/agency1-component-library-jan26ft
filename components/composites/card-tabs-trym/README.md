# Card + Tabs

A game-themed card component with three interactive tabs.

## Features

- Fixed-size card layout
- Three tabs: Info, Stats and Requirements
- Tab content changes without reloading the page
- Active tab styling
- Hover effects
- Dark purple "void" theme
- Responsive centered layout

## How it works

The component uses buttons with `data-tab` attributes to connect each tab to its matching content section.

JavaScript removes the `active` class from all tabs and content sections, then adds it to the selected tab and its corresponding content.

## Files

- `index.html` - Component structure
- `style.css` - Card, tab and void-theme styling
- `script.js` - Tab switching functionality
