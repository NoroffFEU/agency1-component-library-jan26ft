# Switch-kompnent

an easy toggle-switch (on/off-switch) build with an hidden checkbox og a clean CSS.

## How to use 
copy the '<label class="switch">' - from 'index.html', and include 'style.css'. The hidden '<input type="checkbox">' keeps the state - you can read it in JavaScript with 'checkbox.checked'.

## Designchoice
-use a real '<input type="checkbox">' for avaliablety and form.
-the  switch turns green when #53b556 is on, thats a obious checked colour. 
-soft transition with CSS, the button glides smooth instead of jumping.
